# TX Chat

Version 1.0.1

A Windows setup program that opens [Stoat](https://stoat.chat) on a private server, https://txchat.duckdns.org.

Download and run [tx_chat.exe](https://github.com/philipvern-dot/tx-chat/releases/download/v1.0.1/tx_chat.exe).

The setup explains that TX Chat redirects Stoat to that private server. The original Stoat shortcut is left unchanged. Stoat does not open on its own at sign-in. Quit TX Chat, then open the original Stoat shortcut, to use the public server.

If Stoat is not already installed, the setup downloads it from the official Stoat release. Stoat itself is not included in this repository.

TX Chat adds a desktop shortcut and a Start menu shortcut. Uninstall TX Chat from Windows Settings. That removes the TX Chat shortcuts. Stoat and the original Stoat shortcut stay installed.
